# 跳跃槽位：原地扇翼（2026-11-02）

用户在逐项讨论中确定的方向：

- 站姿自然稳当，双脚略分开。双手在腰后轻轻交握，从正面看双手被身体遮住，以自然后收的肩膀和手肘表现这一姿态。脚尖保持着地，脚跟可轻轻抬起。
- 正面朝向用户，神态平静，带不太明显的微笑，睁眼时看向用户；头部轻轻跟随身体起伏。保持当前待机的人物大小与克制、偏冷的画风。
- 翅膀上下大幅舒展：翅尖抬至头部附近，随后下扇至腰裙两侧；两翼几乎同步，但带轻微自然错拍。
- 审样节奏约为一轮 1.2 秒；实际播放由宿主决定。仅用翅膀、发丝和衣摆表达动作，不加气流、光点或其他特效。
- 首个候选被指出身体太僵。用户进一步要求身体自然上下起伏：按 208 px 的宠物画面，头部约上下 3–5 px；翅膀下扇时身体微微上扬，抬翼时柔和回落。
- 头发、衣袖和裙摆轻柔跟随并略有滞后，不遮挡脸和翅膀。原先的双手自然垂放方案已被双手背在身后的新要求取代。
- 卷曲的尾巴整体左右轻摆，始终位于画面右侧，保持原本的曲线；按 192 px 宽的宠物画面，尾尖约移动 3–5 px。尾巴与翅膀处于同一循环周期，但有轻微滞后。
- 虽然宿主槽位叫 `jumping`，用户选择脚尖保持接地；不得为了满足旧版自动“腾空高度”指标而违背这一设计。若质量工具报告未腾空，应保留原始报告并如实说明这一有意差异。

```bash
python art/animation/jump-grounded-20261102/rebuild_atlas.py \
  --base-atlas art/animation/v1.2.0-dev-20261102/spritesheet.webp \
  --output /tmp/gptchan-grounded-rebuilt.webp
```
