# GPT酱形象与动作基线

待机／等待样稿及其余七种动作的关键姿势均已获使用者认可。本轮九动作与十六向注视已完成图集和离线视觉验收，更新为 classic 的可安装候选素材；实机触发与跟随仍待验收。样稿是本项目的非官方二创提案，不是 ZipZipPipe 发布或确认的新设定。

## 参考优先级

1. ZipZipPipe 原作立绘和作者 Q 版。公开收录记录指向 [Pixiv《AI娘化》](https://www.pixiv.net/artworks/148186519) 与 [《大AI和小AI们》](https://www.bilibili.com/video/BV1tE9XBbErS/)。本轮沿用此前查看的收录预览，未再次取得原站核验。
2. 使用者提供、具体绘制者未核实的社区三视图，只作结构辅助。
3. 现有 Pet 为尺寸与可读性基线，其“神态疏淡”描述不等于作者完整人格设定。

## 保持项

白发紫瞳、白龙角、尖耳、白紫礼服、明确的翼膜结构和有鳞片的长尾；以少量清楚的结形／花形饰物组织服装，保持冷色银饰和垂坠层次。头部、角、发饰、裙装、翼尾的相对尺度在同套动作中固定。

气质目标是从容、有主见、专注、略有俏皮。它是本项目的视觉解释，不伪称作者明示性格。眼神应有注意力，避免把疏淡画成疲惫；亲近感通过细小动作表达。

待机：稳定放松站姿，轻微笑意。等待：略抬眼、侧头或小幅摊掌，清晰地等待回应。已接受的角色方向位于 art/samples/gptchan-study-v1.png；下一批动作目标与验收范围见 [正式迭代关键姿势说明](../art/keyposes/v2/BRIEF.md)。

## 完整动画验收

- 九种动作及 16 格视线均完整，未用格全透明；左右行进、循环首尾和相邻视线方向自然。
- 原尺寸／半尺寸、浅色／深色背景检查，头身比例稳定，手部和翼尾无突变。
- 保留既往已明确的跳跃离地感、腾空时中性微张口，以及左行头部比例要求，未来修订逐帧核对。
- 生成素材、最终图集和衍生预览分清；记录改了哪些行及哪些行应保持一致。
- 完整图集需要实机播放验收。高分辨率样稿通过不代表缩到 192×208 后必然清晰。

本轮实际结果、已知限制与用户选稿记录见 [动画审看](ANIMATION-REVIEW.md)。使用者更喜欢十六向第二行第一组的脸型与神态；第二组第5、6格存在过度侧转造成的侧脸／颈部变形，弃用整组。后续不因几何校验需要而采用已被否定的脸型。
